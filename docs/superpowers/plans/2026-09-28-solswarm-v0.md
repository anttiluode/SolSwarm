# SolSwarm v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible three-gate SolSwarm v0 plus a static visualization: world-written spectral mode shifts, importance-weighted Oja under biased scouts, and an honest closed-loop adaptive-sampling boundary.

**Architecture:** Keep the scientific implementation in small NumPy modules under `src/solswarm`. Each gate exposes a deterministic receipt function used by both tests and `experiments/run_all.py`. The public page is standalone JavaScript and mirrors only the explanatory geometry; committed Python receipts remain authoritative.

**Tech Stack:** Python 3.10+, NumPy, pytest, vanilla HTML/CSS/JavaScript, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-28-solswarm-v0-design.md`

## Global Constraints

- Python 3.10+.
- NumPy is the only runtime dependency.
- Pytest is the test dependency.
- Every stochastic result uses explicit seeds.
- Preserve negative Gate C results.
- `index.html` must run as static GitHub Pages content with no build step.

## Review Focus

- Probability vectors must remain normalized and nonnegative.
- Importance weights must use target probability divided by proposal probability, never the inverse.
- Eigenvector comparisons must be sign-invariant.
- Adaptive proposal must retain nonzero uniform exploration so importance weights remain finite.
- Gate C reporting must not relabel "bias corrected" as "beats uniform."
